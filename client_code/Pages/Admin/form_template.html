Bring in the old PlanPlate

Moves restaurants, opening hours, tables, bookings, staff, sign-ins (people keep their passwords), gallery photos and menu-file names from restaurant.planplate.com into this app. Each restaurant keeps its old ID, so its website code and printed QR codes keep working.

  1. Open the old restaurant.planplate.com app in Anvil, then Data.
  2. For each table, use Download as CSV: users, new_staff_access, restaurants, reservations, menu_files, gallery_flags, cloudinary_related and special_actions.
  3. Choose all the files here, check what's in them, then import. Importing twice is safe: nothing is added twice.

Demo data

Maison Lumière, a made-up bistro with bookings, guests, a menu and a website, so PlanPlate never looks empty. It belongs to a demo owner, so removing it never touches real restaurants. Once removed, it stays removed until you load it again.
